# Angry Judge: Short Rant — The Office Printer

One short, funny rant about the most reliable traitor in any office: the
printer that works perfectly all week and only breaks the moment you
actually need it. Specific, concrete, and — for anyone who has ever
apologized to a machine — painfully shared.

The rant is validated (1–400 characters, plain ASCII, non-empty) and
written to `entry.txt` by `main.ts` (Node stdlib only, deterministic).
